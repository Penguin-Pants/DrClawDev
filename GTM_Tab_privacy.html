Privacy Policy — [EXTENSION NAME]

Last updated: [DATE]

Summary

The extension does not collect, transmit, sell, or share any personal data. Everything it stores is kept locally in the user's browser. The only outbound request the extension makes is a read of a public Google Sheet that the team uses to manage the new-tab page's content.

What the extension does

[EXTENSION NAME] replaces the Chrome new tab page with a dashboard of internal go-to-market resources — positioning, the current sales deck, curated Drive links, recently updated items, and key contacts — pulled from a Google Sheet that has been published to the web as CSV. The extension fetches that CSV on a schedule, parses it, and renders the result on the new-tab page.

The extension does not collect or store any of the following: personally identifiable information, health information, financial information, authentication credentials, personal communications, location, browsing history, in-extension activity logs, or the contents of any web pages the user visits.

Permissions explained

  • storage — caches the parsed Google Sheet content locally so the new-tab page renders instantly while a fresh copy is fetched in the background.
  • alarms — schedules a periodic background re-fetch of the Google Sheet (default every 30 minutes) so the page stays current.
  • Host permission https://docs.google.com/* — allows the background service worker to fetch the published Google Sheet's CSV export endpoint. The request is anonymous (credentials: "omit"), so no cookies or authentication tokens are sent.

Remote code

The extension does not load or execute any remote JavaScript or WebAssembly. All scripts it runs are bundled with the extension package. There is no use of eval, new Function, dynamic <script> insertion, or remote module imports.

Third parties

When the new-tab page is open the user's browser fetches the following passive resources directly from third-party servers. The extension does not send any user data to them; their servers only see whatever a normal browser request includes (IP address, user agent, Referer):

  • Google (docs.google.com) — the configured Google Sheet's CSV export. Subject to Google's privacy policy.
  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com) — serves the Geist typeface CSS and font files. Subject to Google's privacy policy.
  • Sanity CDN (cdn.sanity.io) — serves the default GetVocal wordmark logo SVG. Subject to Sanity's privacy policy.
  • Google Drive (drive.google.com) — only loaded when an administrator has chosen to set a Drive-hosted image URL in the sheet's Config tab (background image, light-mode logo override, or dark-mode logo override). Subject to Google's privacy policy.

These are standard browser asset loads. The extension does not embed analytics, telemetry, advertising, or any third-party SDK.

Children

The extension is intended for internal business use by employees and is not directed to children under 13. It does not knowingly collect information from children.
