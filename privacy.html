Privacy Policy for URL2MD

Last updated: May 2026

URL2MD does not collect, store, transmit, sell, or share any personal data. Everything the extension does happens locally inside your browser and on your own computer. There is no account system, no server, no analytics, no telemetry, and no third-party services.

What the extension does

URL2MD lets you save a single open tab — or every tab in your current window — as a Markdown (.md) file in your computer's Downloads folder. When you trigger a save, the extension:

  1. Reads the HTML of the page or pages you asked to save.
  2. Extracts the main article content using Mozilla's open-source Readability library and converts it to Markdown using the Turndown library. Both libraries run locally inside your browser.
  3. Writes the resulting .md file to your Downloads folder via Chrome's standard downloads API.

All of this processing happens on your device. The page content never leaves your computer.

Data the extension accesses (and does not store)

Data How it's used Stored? Sent off-device?
The HTML content of tabs you actively choose to save Converted to Markdown in memory and written to your local Downloads folder No No
The URL and title of tabs you actively choose to save Used to skip browser-internal pages (e.g. chrome://) and to generate the saved filename No No
The list of tabs in your current window Read only when you click "Download all open tabs as Markdown", to know which tabs to convert No No

The extension does not read your browsing history, not monitor pages in the background, and not track which sites you visit. It only acts on tabs in direct response to a click you make — either on the toolbar icon or on the right-click menu item.

Permissions explained

  • activeTab / scripting / tabs / host permission <all_urls> — used to inject the local Readability and Turndown libraries into the tab(s) you ask to save, so the page's content can be converted to Markdown. These permissions are exercised only when you trigger a save.
  • downloads — used to write the generated .md file to your Downloads folder.
  • contextMenus — used to add the right-click menu items "Download this page as Markdown" and "Download all open tabs as Markdown".

Remote code

The extension does not load or execute any remote code. All JavaScript it runs is bundled inside the extension package and ships through the Chrome Web Store. There are no network requests, no CDN calls, and no use of eval or remote scripts.

Third parties

There are no third-party services, SDKs, analytics providers, ad networks, or trackers in this extension.

Children

The extension is not directed at children. It does not collect any data from any user, including children.
